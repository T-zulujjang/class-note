클래스 노트 개인정보처리방침

시행일: 2026년 10월 17일

클래스 노트(https://t-zulujjang.github.io/class-note/)는 수업 판서를 위한 웹 앱입니다. 클래스 노트는 이용자의 개인정보를 별도의 서버로 수집하거나 보관하지 않습니다.

1. 처리하는 정보

  • 필기 내용: 이용자가 클래스 노트에 쓴 필기(선의 위치, 색, 굵기), 글상자, 이용자가 붙여 넣은 그림, 학습지 파일 이름.
  • 구글 계정 정보(구글 로그인을 한 경우에만): 화면 오른쪽 위에 표시하기 위한 이름, 이메일 주소, 프로필 사진.
  • 카메라 화면: 카메라 탭과 '카메라로 찍기'에서 이용자가 허용한 경우에만 카메라를 켭니다. 실시간 화면은 이용자의 기기 화면에만 보이며 저장하거나 전송하지 않습니다. 이용자가 '찍어서 넣기'를 누른 사진만 필기 안의 그림으로 들어가 필기와 같은 곳에 저장됩니다.
  • 학습지 PDF: 이용자가 클래스 노트에서 연 PDF 파일. 로그인하지 않은 경우 이용자의 기기 안에서만 열리며 어디로도 전송되지 않습니다. 로그인한 경우에는 다른 기기에서도 열 수 있도록 이용자 본인의 구글 드라이브에 사본이 보관됩니다.

2. 저장 위치

  • 이용자의 기기: 필기 내용은 이용자 브라우저의 저장소(localStorage)에 저장됩니다.
  • 이용자 본인의 구글 드라이브(로그인한 경우): 필기 내용과 학습지 PDF 사본이 이용자 드라이브의 '클래스 노트' 폴더에 파일로 저장됩니다.
  • 클래스 노트 운영자는 이용자의 필기 내용이나 계정 정보를 볼 수 없으며, 별도의 서버나 데이터베이스를 운영하지 않습니다.

3. 구글 드라이브 권한

클래스 노트는 구글 드라이브 권한 중 drive.file 범위만 요청합니다. 이 권한으로는 클래스 노트가 직접 만든 파일만 보고 수정할 수 있으며, 이용자 드라이브의 다른 파일에는 접근할 수 없습니다. 구글 사용자 데이터는 필기 저장·불러오기 기능에만 사용하며, 광고·판매·제3자 제공 등 다른 목적으로 사용하거나 다른 곳으로 전송하지 않습니다.

클래스 노트의 구글 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관 기간과 삭제

  • 드라이브에 저장된 필기는 이용자가 직접 지울 때까지 이용자의 드라이브에 남습니다. 드라이브의 '클래스 노트' 폴더에서 언제든 지울 수 있습니다.
  • 기기에 저장된 필기는 브라우저의 사이트 데이터를 지우면 삭제됩니다.
  • 클래스 노트의 드라이브 접근 권한은 구글 계정의 서드 파티 연결에서 언제든 해제할 수 있습니다. 클래스 노트의 로그아웃 메뉴로도 권한이 해제됩니다.

5. 이용하는 외부 서비스

  • 구글 로그인 및 구글 드라이브 API (Google LLC)
  • PDF 표시 도구(pdf.js)와 글꼴을 공개 CDN(cdnjs, Google Fonts)에서 불러옵니다.
  • 웹 페이지는 GitHub Pages(GitHub, Inc.)에서 제공됩니다.
